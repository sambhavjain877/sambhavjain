# Sambhav Jain — Developer Portfolio

A responsive, dark-themed personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

No build tools or dependencies are required.

## Before publishing
- Replace every generic `https://github.com/` link with your actual GitHub profile or project repository.
- Replace the LinkedIn link with your profile.
- Confirm the degree/branch wording and skills match your real background.
- Update project cards only when the projects are actually built. Add screenshots and live demos.
- Add your professional email only if you're comfortable making it public.

## Publish with GitHub Pages
1. Create a GitHub repository named `portfolio` (or another name you like).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the published URL shown on the Pages settings page.
